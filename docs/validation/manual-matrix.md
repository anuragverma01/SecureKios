# Windows manual validation matrix

Run on each supported Windows image and record OS build, edition, app version, policy version, and result for: elevated installation; unsupported-edition rejection; kiosk sign-in/startup; full-screen/title-bar/minimize/maximize behavior; Shell Launcher restart behavior; Keyboard Filter shortcuts; AppLocker/Assigned Access allowlisting; Alt+Tab/Alt+F4; Ctrl+Alt+Delete; crash and restart-loop limits; Windows restart/shutdown; wrong/correct/cancelled exit flow; credential rotation; repair; removal; administrator recovery; and uninstall.

No Windows-specific item should be marked passing from Linux CI alone.
